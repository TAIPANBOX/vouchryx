# vouchryx 0.6.0

## Upgrade first: two changes that can stop a start or change what is written

**1. With `VOUCHRYX_SIGNER=keyryx`, set `VOUCHRYX_KEYRYX_ROOT_PIN` before you start 0.6.0.** Without it, vouchryx now refuses to start. The variable takes the key ids (kids) of the delegation root, one ES384 key and one ML-DSA-65 key, comma separated. Get them from the root's key set that Keyryx serves at `/v1/jwks/keyryx.delegation-root`. From this release vouchryx checks the statement Keyryx gives for its working key against those kids before the key signs, and a missing or malformed pin stops the start with a message that names the variable. If you use the file signer (`VOUCHRYX_SIGNER` unset or `file`), nothing here applies.

**2. The event file: mode and owned directory.** Since agent-stack-go v2 (below), a stream file vouchryx creates, including `VOUCHRYX_EVENTS_PATH`, is mode `0640`, not `0644`: the owning account and its group can read it, and no other account can. A new stream file is created only in a directory vouchryx's account owns, and an existing file is opened as it is. A bus directory that is shared between services and not owned by vouchryx's account gets no new stream, unless each file is created beforehand by the uid of the service that writes it. Before you start 0.6.0, check who owns the bus directory and the mode of each stream file in it.

## Changed since 0.5.0

- **Keyryx's statement for the working key is verified against a pinned root (#54).** This is change 1 above. Rotating the root is a new pin and a restart.
- **The agent-stack-go pin moves to the v2 module path, v2.0.0 (#55).** The shared wire-type import moves to `github.com/TAIPANBOX/agent-stack-go/v2`. This is change 2 above.
- **The image is signed in the legacy format (#56).** The image sign step adds `--new-bundle-format=false --use-signing-config=false`, with a comment above it, because the cluster admission controller (policy-controller v0.15.1) reads only the legacy `.sig` tag. cosign stays at v3.1.3, and the `sign-blob` steps are unchanged. Remove both flags when policy-controller reads bundles.

No other commit lies between the 0.5.0 tag and this release.

Pull `ghcr.io/taipanbox/vouchryx:v0.6.0` once the change 1 variable is set.
