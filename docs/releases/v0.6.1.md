# vouchryx 0.6.1

A patch release on 0.6.0. The binary and the image are built with Go 1.27.3, which fixes GO-2026-6809 in `crypto/x509`. The 0.6.0 image was built with Go 1.27.2. Nothing an operator sets or sees moves: no variable, route, token claim or file mode changes, and nothing in the 0.6.0 upgrade section needs doing again.

## Changed since 0.6.0

- **Go 1.27.3 (#60).** The `toolchain` line in `go.mod`, the Go version in the CI and release workflows, the Go version of the build image in the `Dockerfile`, and the gate anchors that name the old pin move to 1.27.3.
- **The agent-stack-go pin moves to v2.0.1 (#58).** That release changes no Go code; `go.mod` and `go.sum` move to it and nothing else changes.
- **Documentation (#59).** The 0.6.0 notes state the event stream file rule in their Upgrade section.

No other commit lies between the 0.6.0 tag and this release.

Pull `ghcr.io/taipanbox/vouchryx:v0.6.1` and restart.
