# vouchryx 0.8.0

A minor release on 0.7.0. A revoke key can now be scoped to the rights and the parties its holder needs. A bare key keeps every right, as before. The release is also built with Go 1.27.4, which fixes GO-2026-6859.

## Upgrade

- **Nothing changes for an existing key.** A `VOUCHRYX_REVOKE_KEYS` entry with no `|` is a bare key and may revoke, ban and lift anyone, exactly as in 0.7.0.
- **A scoped entry is `key|rights|prefix`.**
  - `rights` is one or more of `revoke`, `ban` and `lift`, joined by `+`.
  - `prefix` is a URI prefix that contains `://` and ends in `/`, for example `user://acme.example/`. The closing `/` is what keeps `user://acme.example/` from also covering `user://acme.example.evil/`.
- **What a scoped key may do.** Only its rights, only for a subject under its prefix, and never revoke by `jti`, because a jti names no party the prefix could be checked against. Anything else is a 403 that names the reason in the operator's log: `revoke_key_scoped_to_subjects`, `revoke_key_lacks_<right>` or `subject_outside_revoke_key_scope`.
- **A scope that cannot be read exactly stops the start.** The message names the entry's position and never its key. A bare key that contains a `|` is read as a scope, so such a key must be replaced before the upgrade.

Rollback is to run the 0.7.0 image again. A scoped entry is then refused, because 0.7.0 reads the whole entry as one bare key, which no caller presents.

Pull `ghcr.io/taipanbox/vouchryx:v0.8.0` and restart.

## Changed since 0.7.0

- **Scoped revoke keys (#72).** The motivating case is an automated deprovisioning feed that bans people who were disabled at an identity provider. With `secret|ban+revoke|user://acme.example/` it can stop people, but it cannot lift a ban or touch an agent, so a leak of its key costs no more than that.
  - Both routes check the scope before anything is written. The lift route checks it before the ban list, so a key outside its scope cannot learn whether a party is banned.
  - This is CLAUDE.md invariant 30, held by the gate `scripts/every-revoke-asks-its-scope.sh` with five cases in `gates-have-teeth.sh`.
  - Nine tests were each run red first, one of them on the built binary. Ten planted faults were each caught by a named test.
  - Six scenarios were added to `features/agent-credentials.feature`.
- **Go 1.27.4 (#71)** for GO-2026-6859.
- **README and CI (#69, #70).** The diagram shows the wave's edges, and the crypto and enforcement-point paragraphs name wardryx's token check. The CI actions group is updated.

No other commit lies between the 0.7.0 tag and this release.
